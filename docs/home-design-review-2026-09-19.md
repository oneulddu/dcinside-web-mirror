# 홈 디자인 평가 기록

요청: 홈페이지를 Gemini 3.8 Flash에 실제 화면으로 평가받고 수정 후 재평가한다.

## 평가 방법

- 호출 모델: 기존 Codex CLI 연결의 `google-antigravity/gemini-3.8-flash`.
- 스크린샷: 실제 Flask 홈페이지를 Chrome에서 1280×900, 390×844로 렌더링한
  라이트·다크 네 장을 각 호출에 이미지로 첨부했다.
- 고정 배점: 정보 위계 20, 정렬과 간격 25, 가독성과 대비 20,
  모바일 적합성 20, 시각 일관성과 조작 명확성 15.
- 화면에 보이는 결함에 근거해 감점하도록 요청했다. 측정 가능한 값은 브라우저 실측과
  색 대비 계산을 함께 제공했다. 최종 점수는 이 모델의 시각 평가이며 보편적 품질 인증이 아니다.

## 반복 결과

| 이미지 묶음 | 점수 | 조치 |
|---|---:|---|
| before | 69 | 순위 고정폭, 제목/ID 묶음, 텍스트 등급, 44px 컨트롤 적용 |
| round03 | 91 | 모바일 갱신 시각 분리, 대비 보정, 검색창과 버튼 형태 정돈 |
| round04 | 76 | 상단 간격을 24px로 압축, 다크 괘선 보강, 채움형 검색 버튼 |
| round05 | 100 | 평가자가 남은 시각적 결함 없음을 보고 |

중간 `round02`는 템플릿 캐시로 수정 전 구조가 남아 있던 캡처여서 평가 결과를 제외했다.
이후 서버를 재시작하고 `home-view` 클래스와 변경된 DOM을 확인한 뒤 캡처했다.
점수가 단조롭게 상승하지 않았으며 최종 호출에는 직전 평가 원문을 제공해
같은 감점 사유의 해결 여부를 먼저 확인하도록 했다.

## 별도 검증

- `MIRROR_ENV=development make test PYTHON=/tmp/mirror-design-0919-venv/bin/python`:
  683개 통과. 기존 테스트의 HTML 원문 문자열 검사는 태그가 추가된 제목을 허용하도록
  HTML 파서로 실제 표시 문구를 확인하게 수정했다. 외부 호출 횟수 검사는 유지한다.
- 실제 원본 응답 기반 검색(만화), 초기화, 페이지 이동, 최근 탭 이동을 확인했다.
- Tab 본문 바로가기, 검색 포커스, Enter 검색 제출, Space 테마 전환과 새로고침 후 유지,
  이미지 차단 메뉴를 확인했다.
- 별도 로컬 QA 서버에서 실제 템플릿을 긴 이름·ID, 1/2/3자리 순위, 외부 갤러리,
  검색 결과 없음, 원본 조회 오류로 렌더링했다. 320/390/768/1280px × 두 테마 × 네 상태의
  32개 조합에서 가로 넘침과 JavaScript 예외가 없었다. 외부 링크의 `_blank`와 `noopener`도 확인했다.
- 390px에서 모든 순위 제목 시작 x=56px, 순위 열 28px, 기본 행 64px,
  헤더 버튼 44×44px를 실측했다.
- 보조 텍스트 대비: 라이트 5.93:1 / 다크 6.91:1.
  강조 텍스트 대비: 라이트 5.43:1 / 다크 7.53:1. 일반 텍스트 AA 기준으로 확인했다.
  모델 보고서의 포괄적인 AAA 표현은 검증 결론으로 사용하지 않는다.

원본 이미지와 모델 평가 응답은 로컬 작업 산출물 `mirror-home-2026-09-19`에 보관한다.
운영 반영은 기존 GitHub Actions의 테스트, SSH 배포, 헬스 체크, 서버 커밋 일치 확인을 따른다.
