# 포커고수 미러 개선 목록 (2026-09-28)

## 성능과 안정성

- [x] 1. 이미지 응답 캐시: `/poker/media`가 DC 미디어와 같은 `MEDIA_CACHE_MAX_AGE`를 쓴다.
- [x] 2. 원본 장애 때 지난 캐시: 502·503이면 `MIRROR_POKER_STALE_SECONDS`(600초) 안의 지난 성공 데이터를 안내와 함께 보여 준다.
      404·403·400은 덮지 않는다. 목록·글·댓글 JSON 모두 적용.
- [x] 3. 워커 간 요청 제한 공유: 60초 쿨다운과 0.3초 간격을 `MIRROR_POKER_STATE_FILE` 파일 잠금으로 공유한다.
      시계가 뒤로 가도 대기는 0.3초, 차단은 60초를 넘지 않는다.
- [x] 4. 정리된 HTML 캐시: 본문·댓글 정리는 캐시를 채울 때 한 번만 한다.
- [x] 5. 연결 재사용: 스레드마다 `curl_cffi` 세션을 재사용하고 오류·크기 초과·차단 때 버린다.
- [x] 6. 이전 댓글 페이지 캐시 5분.

## 기능

- [x] 7. 유튜브 재생: 본문의 정확한 YouTube embed만 `youtube-nocookie.com`으로 남긴다. 댓글 iframe은 계속 지운다.
- [x] 8. 파서 고장 감지: 구조 오류·첫 페이지 0건 경고 로그, `scripts/poker_smoke.py` 실측 점검.
- [x] 9. 댓글 스팸 접기: 포커고수 댓글에도 적용하고 이전 댓글이 붙을 때마다 다시 계산한다.
- [x] 10. 게시판 검색: `/poker/<board>/search?s=1..5&v=&page=`. 글·하단 목록·돌아가기·오류 재시도에 검색 조건 유지.
- [x] 11. 최근 본 게시판: `poker:<id>`·`kind=poker`로 저장해 디시 기록과 분리한다.
